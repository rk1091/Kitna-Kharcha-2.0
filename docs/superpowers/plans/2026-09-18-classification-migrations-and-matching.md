# Classification Accuracy, Prisma Migrations, and Substring Matching Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Establish formal Prisma migration history, clean and merge duplicate categories, implement indestructible case-insensitive substring matching for merchants and classification rules, enable auto-creation of rules in Copilot, and batch LLM classification to save tokens and prevent rate limits.

**Architecture:** 
1. Database versioning is formalized via standard Prisma migrations in `backend/prisma/migrations`.
2. Category taxonomy is unified by consolidating `Food` into `Food & Dining` across existing data and seed scripts.
3. Merchant recognition and classification rules shift from fragile boundary regexes to case-insensitive substring inclusion (`.toLowerCase().includes()`), testing both raw description and normalized merchant name so variations like `: RAZ*SwiggyBangalore C`, `WWW DINEOUT CO IN`, and `00: EMINYKAA` match reliably without relying on perfect string stripping.
4. Auto-learning engine in `TransactionsService` and new `create_classification_rule` tool in `CopilotService` write and read consistent substring condition formats.
5. `PipelineProcessor` and `LLMClassifierService` process unclassified transactions in batched chunks of 25 with server-directed 429 retry backoff.

**Tech Stack:** NestJS, Prisma 5, PostgreSQL 15, BullMQ, Google GenAI SDK (`@google/genai`), Vitest.

**Spec:** Current session requirements for Prisma migration history, boundary-tolerant case-insensitive matching, category deduplication, Copilot rule creation, and batched classification.

## Global Constraints
- Do NOT stop or kill running servers (`nest start --watch`, Vite, Docker containers).
- Preserve existing comments and unrelated application logic.
- All tests must pass via `npm test` and `npm run test:e2e`.
